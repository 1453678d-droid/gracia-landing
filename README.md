# ГрациЯ — дизайн-концепция лендинга

Полная адаптивная HTML-страница по визуальному макету и текстовому прототипу.

Сайт: https://1453678d-droid.github.io/gracia-landing/

## Доступ

Репозиторий публичный по решению владельца. Исходный код и изображения доступны всем. Страница сайта открывается без входа.

В HTML добавлен `noindex,nofollow,noarchive`, в robots.txt — `Disallow: /`. Это просьба поисковикам не индексировать сайт, а не защита доступа и не способ скрыть сам репозиторий на GitHub. Ссылку можно передавать дальше.

## Статус макета

Форма демонстрационная, данные не отправляет и не сохраняет. Для команды, отзывов, карты и видео обозначены места под реальное наполнение. Фотографии, изображения, шрифты и стили находятся в этой папке; внешняя сборка не требуется. Лицензии шрифтов сохранены в assets.

## Просмотр и публикация

Для локального просмотра откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

GitHub Pages публикует ветку `main`, папку `/(root)`. Пути к ресурсам относительные и поддерживают адрес сайта в подпапке.
