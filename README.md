# ГрациЯ — дизайн-концепция лендинга

Полная адаптивная HTML-страница по визуальному макету и текстовому прототипу. Откройте `index.html` в браузере; сборка и установка зависимостей не требуются.

## Доступ

Репозиторий должен оставаться **приватным**. Макет предназначен для просмотра по прямой ссылке без входа. Запрет индексации задан в HTML и robots.txt; это просьба поисковикам и не защита паролем. Посетители могут передавать ссылку дальше.

Публикация пока не выполнена. GitHub Pages из приватного личного репозитория требует GitHub Pro либо другого подходящего тарифа. Не переводить репозиторий в публичный для обхода ограничения.

## Статус макета

Форма демонстрационная, данные не отправляет и не сохраняет. Для команды, отзывов, карты и видео обозначены места под реальное наполнение. Фотографии, изображения, шрифты и стили находятся в этой папке; внешняя сборка не требуется. Лицензии шрифтов сохранены в assets.

## Публикация

Выбор хостинга и включение публикации выполняются после подтверждения доступного тарифа. Сам HTML подготовлен для размещения в корне сайта или в подпапке GitHub Pages: пути к ресурсам относительные.

Документация GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
